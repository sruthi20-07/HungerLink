# HungerLink – MVP Build Plan

PHASE 1 — Project Setup
1. Initialize backend: Node.js + Express + TypeScript
2. Initialize frontend: React + TypeScript
3. Connect MongoDB Atlas

PHASE 2 — Authentication
4. User model (Canteen, NGO)
5. Register / Login APIs
6. JWT auth middleware

PHASE 3 — Core Functionality
7. FoodPost model (foodType, quantity, location, expiry, status)
8. Create surplus food API
9. List surplus food API
10. Accept pickup API
11. Mark pickup completed API

PHASE 4 — Frontend
12. Login & Register pages
13. Canteen dashboard (create surplus)
14. NGO dashboard (view & accept surplus)
15. Status update UI

PHASE 5 — Demo Ready
16. Seed demo data
17. End-to-end test
